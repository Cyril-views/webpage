Free learning notes

Small steps toward stronger technology skills.

Use these practical prompts to plan your learning. They are starting points, not a substitute for hands-on practice or a complete course.

PYTHON / BEGINNER

Before your first Python project

Choose a small task you already understand, such as organizing a folder or summarizing a simple table. Break it into inputs, steps, and an expected result before writing code.

  • Write down the result you want in one sentence.
  • Practise variables, conditions, loops, and functions separately.
  • Test one ordinary case and one awkward edge case.
  • Explain what the code does without relying on line-by-line memorization.

DATA / ANALYTICS

A simple checklist for trustworthy SQL analysis

A query can run successfully and still answer the wrong question. Make the question and the grain of your data explicit before interpreting a result.

  • Define what one row represents in each table.
  • Check join keys and look for unexpected row multiplication.
  • Decide how missing values and duplicate records should be treated.
  • Compare totals with a simple baseline and state important assumptions.

CAREER / PROJECTS

How to present a technical project clearly

A useful project story connects a real question to the work you did and the limits of what you learned. Be clear about your own contribution.

  • Describe the problem and who the result is for.
  • Summarize the data, tools, and approach.
  • Show one finding or design decision and how you checked it.
  • Explain what you would improve with more time or better data.
